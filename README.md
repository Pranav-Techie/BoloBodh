# BoloBodh AI 📚🎙️
### Learn in Your Language. Ask Freely. Understand Better.

**BoloBodh AI** is a multilingual, voice-first AI learning assistant designed to make learning more accessible, interactive, and personalized for school students. Students can ask academic questions in their preferred language, listen to spoken explanations, summarize study materials, generate practice quizzes, and revisit concepts through revision support.

Built for the **Great Indian AI Internship Challenge by Gnani AI**, BoloBodh explores how Indian speech AI and conversational AI can help students learn beyond language barriers.

---

## 🌟 The Problem

Many students find it difficult to learn when educational resources, explanations, or digital tools are not available in a language they are comfortable with. Reading lengthy study materials, asking questions confidently, and revising concepts can also be challenging.

BoloBodh AI aims to make these activities simpler through voice interaction, multilingual learning support, and AI-assisted study tools.

## 💡 Our Solution

BoloBodh AI brings multiple learning tools into one student-friendly platform. Students can ask questions, receive explanations, work with PDF study materials, practice with quizzes, and access revision support through a single dashboard.

The goal is not just to provide answers, but to help students understand concepts and practice what they learn.

## ✨ Key Features

### 1. 🎙️ Voice-First Learning
- Convert spoken questions into text using Gnani AI speech-to-text.
- Listen to AI-generated explanations using text-to-speech.
- Make learning more accessible to students who prefer speaking and listening over typing and reading.
- Support a conversational learning experience.

### 2. 🌍 Multilingual Learning
- **Hindi** — ask questions and learn in Hindi.
- **English** — learn and practice in English.
- **Hinglish** — interact using natural Hindi-English mixed language.

The application is designed around a student's language preference, helping make explanations easier to understand. Additional language support can be expanded as compatible models and workflows are integrated and tested.

### 3. 🤖 Ask a Doubt — AI Learning Assistant
- Ask academic questions directly from the student dashboard.
- Get AI-generated explanations tailored to the question.
- Explore concepts across different school-level topics.
- Ask follow-up questions to continue learning.
- Use voice interaction where supported.

### 4. 📄 Study Materials and PDF Summarization
Turn lengthy study material into a more manageable learning resource.

- Upload a supported PDF study document.
- Extract and process its readable content.
- Generate an AI-powered summary of the material.
- Review important concepts in a concise format.
- Use summarized content as a starting point for revision.

**Why it matters:** Students can review lengthy notes and chapters more efficiently instead of repeatedly reading an entire document.

*Summary quality depends on document readability, extracted text, and the AI model's output.*

### 5. 📝 AI-Generated Practice Quizzes
- Generate practice questions with AI.
- Test understanding of a topic or study material.
- Submit answers and receive feedback.
- See scoring and identify areas that need further revision.

**Why it matters:** Students can move from passively reading material to actively checking their understanding.

### 6. 📚 Revision Notes
- Access revision support through a dedicated section.
- Revisit important learning points.
- Keep study and revision activities organized.

### 7. 📊 Quiz History and Learning Continuity
- Review previous quiz attempts where saved.
- Revisit performance and feedback.
- Use past attempts to identify concepts that need more practice.

### 8. 👤 Student Dashboard and Preferences
- Access learning features through a unified dashboard.
- Set language preferences for a more personalized experience.
- Navigate between doubt solving, study materials, quizzes, revision notes, and history.

## 🧠 Gnani AI Integration

BoloBodh AI was developed for the **Great Indian AI Internship Challenge by Gnani AI**, with a focus on applying speech technology to an accessible, real-world learning use case.

The project integrates Gnani AI speech services:

| Technology | Purpose |
|---|---|
| **Gnani AI Prisma v2.5 (STT)** | Converts speech into text |
| **Gnani AI Timbre v2.5 (TTS)** | Converts text into spoken audio |

These capabilities enable voice-based interaction and support a more natural learning experience.

The application also uses an AI language model for conversational explanations, summarization, and quiz generation.

## 🔄 How It Works

1. **Choose a language:** Set the preferred language for the learning experience.
2. **Ask a question:** Type a doubt or use voice interaction where available.
3. **Understand the answer:** Receive an AI-generated explanation and listen to it when speech output is available.
4. **Study smarter:** Upload a PDF and generate a concise summary.
5. **Practice:** Generate a quiz and answer questions to check understanding.
6. **Revise:** Revisit notes and saved quiz history where available.

## 🔐 Privacy and Configuration

BoloBodh uses API credentials and database configuration to connect its services.

- API keys and secrets should be stored in environment variables.
- Never commit `.env` files or private credentials to GitHub.
- Configure the required environment variables separately for local development and deployment.
- Avoid uploading sensitive personal information or confidential documents.
